## Working agreements

- **Communication:** WhatsApp for quick messages, Discord for calls and longer discussions.
- **Decisions:** when we can't agree after a short discussion, we vote. Majority wins and we move on.
- **Git:** everything must end up on `main` (an organizer rule). Use short-lived branches if you like, merge often, and never leave work only on your laptop.
- **Prompts:** save every coding prompt to [`prompts/`](prompts/) as you go. See [prompts/README.md](prompts/README.md).
- **Asking for help:** if you're stuck for more than 20 minutes, say so. Mentors are available at the event too.
- **Code:** no project code before Friday 10:30. Planning, research and learning are fine.
