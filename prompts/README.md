# Prompts

The hackathon [AI policy](https://interledger.org/es/hackathon/ai-policy/) requires the **actual text** of the prompts we used for coding tasks. Summaries don't count.

## Rules

- One file per work session, saved as you go.
- Paste the prompt exactly as you sent it, including follow-ups.
- No secrets: replace private keys, tokens or passwords with `[REDACTED]` before saving.

## File names

```
YYYY-MM-DD_HHMM_<name>_<topic>.md
```

Example: `2026-10-16_1045_jose_incoming-payment.md`

## Template

Copy [`_template.md`](_template.md) to start a new file.

## Tips

- **Claude Code:** `/export` saves the current conversation to a file you can copy here.
- **ChatGPT, Claude.ai, Gemini:** copy your messages from the chat, or use the share or export option.
- **Copilot / Cursor inline suggestions:** there's no prompt to save, so list those files in [AI_USAGE.md](../AI_USAGE.md) instead.
